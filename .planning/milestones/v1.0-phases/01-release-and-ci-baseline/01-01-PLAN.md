<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Developer or CI environment to dependency registry | The resolved dependency graph is fetched and then executed by build tooling. |
| Portable Node helper to local cache | The helper selects a package-manager binary and a cache location on a contributor machine. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | package.json, pnpm-lock.yaml | high | mitigate | Pin pnpm 10.34.5 through Corepack, regenerate the root lockfile from declared manifests, review all importers, and require frozen installs. |
| T-01-02 | Tampering / Information disclosure | portable pnpm cache | medium | mitigate | Keep only pnpm store/cache paths ignored; do not cache credentials, node_modules, or generated application data. |
| T-01-SC | Tampering | Corepack pnpm activation | high | mitigate | Use the researched exact Corepack pnpm release instead of adding a runtime dependency or an unreviewed package-manager bootstrapper. |
</threat_model>
