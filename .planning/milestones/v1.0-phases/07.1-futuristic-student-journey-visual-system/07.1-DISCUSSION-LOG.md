## App-wide typeface

| Option | Description | Selected |
|---|---|---|
| Space Grotesk | Crisp, contemporary geometric sans serif for the whole app. | ✓ |
| Sora | Friendly rounded futuristic sans serif. | |
| Orbitron headings with Sora body | High-tech display headings with a softer text face. | |

**User's choice:** Space Grotesk for now.
**Notes:** The founder reviewed visual examples before choosing.

---

## Red, gray, and white visual balance

| Option | Description | Selected |
|---|---|---|
| White-forward | White pages and cards, charcoal structure, and red actions. | |
| Gray-forward | Soft-gray pages, white cards, and red accents. | |
| Charcoal-forward | Dark charcoal sections with white content and red accents. | |
| Light red/white/silver direction | White and silver as the base, red as an action accent, blush warmth, and deep blue-gray only for readable text. | ✓ |

**User's choice:** Light red, white, and silver; no strong black or charcoal.
**Notes:** The desired tone is light, hopeful, effective, and marketing-aware rather than overly serious. Context-sensitive research supported reserving red for action rather than making it the dominant achievement-context background.

---

## Student-side scene motion

| Option | Description | Selected |
|---|---|---|
| Subtle student-side motion | A slow loop on the student half of people-based scenes. | ✓ |
| Video-style motion | A richer, heavier animated background loop. | |
| Motion on scroll only | A one-time motion effect triggered by scrolling. | |

**User's choice:** Subtle student-side motion.
**Notes:** The civilian half remains still. Movement can combine walking students, trains/buses, and light trails; it should be slow, automatic, and non-distracting. Visitors who prefer reduced motion receive a still version.
