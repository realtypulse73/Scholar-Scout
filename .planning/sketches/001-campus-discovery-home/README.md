# 001 — Campus discovery home

Open `index.html` in a browser. It contains three clickable approaches to the new Scholar Scout start page:

1. **Campus Stories** — a bright, cinematic full-screen discovery feed.
2. **Campus Signal** — the recommended hybrid: a social-style campus moment paired with a factual school listing.
3. **Pathway Lens** — a calmer school-choice view with an immersive watermark and a decision sheet.

## How to review

- Select a version with the three top tabs.
- Use **Next campus** to cycle the sample campus scene and fact card.
- Use the heart to test the saved-school state.
- Use the **Motion** control to pause the decorative movement.
- Use the bottom-right viewport buttons to compare desktop, tablet, and phone framing.

## Boundaries before implementation

The school names, figures, and source labels are intentionally fictional examples. The only image is `assets/campus-discovery-moodboard.png`, original AI-generated art created for this sketch. The production design should use a staff-governed school profile with a short, dated, official-source summary and an approved/licensed image asset. It must never scrape or copy a school webpage wholesale.
