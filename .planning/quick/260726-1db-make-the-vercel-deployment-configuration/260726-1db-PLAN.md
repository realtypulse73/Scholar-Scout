# Quick Task 260726-1db: Make the Vercel deployment configuration build Scholar Scout from its monorepo

## Goal

Make the existing `scholar-scout-web` Vercel project build successfully without moving its app Root Directory, changing package manifests or lockfiles, or touching production data.

## Tasks

### 1. Make root-workspace commands explicit from Vercel's app-root working directory

**Files:**

- `vercel.json`

**Action:** Retain the Next.js framework override, but make the committed install and build commands first change from `apps/web` to the repository root before running the existing frozen install and `build:vercel` script. Set the output directory to the app-root-relative `.next` directory. Do not modify `package.json`, `apps/web/package.json`, `pnpm-lock.yaml`, dashboard command overrides, credentials, or persistence configuration; the configuration must preserve `apps/web` as the Vercel project Root Directory so framework detection uses the package that declares Next.js.

**Verify:**

<verify>
  <automated>node -e "const v=require('./vercel.json'); if (v.framework !== 'nextjs' || !v.installCommand.startsWith('cd ../..') || !v.installCommand.includes('--frozen-lockfile') || !v.installCommand.includes('--ignore-scripts') || !v.buildCommand.startsWith('cd ../..') || !v.buildCommand.includes('build:vercel') || v.outputDirectory !== '.next') process.exit(1)"</automated>
</verify>

**Done:** `vercel.json` describes the exact commands Vercel must execute from `apps/web`, reaches the root lockfile, and names the generated `.next` directory relative to that app root.

### 2. Align the deployment runbook and prove the app-root build path locally

**Files:**

- `docs/vercel-deployment.md`

**Action:** Update the Vercel settings table and local-equivalent section to state that `scholar-scout-web` uses `apps/web` as Root Directory, that the committed commands move to the workspace root for the root lockfile and filtered build, and that `.next` is relative to the app root. Document the required Vercel Build Step setting that permits source files outside `apps/web`; retain Node 20, Corepack, the frozen install contract, Git integration, and production-environment instructions. Do not add secrets or replace committed configuration with dashboard command overrides.

**Verify:**

<verify>
  <automated>set -e; cd apps/web; cd ../..; pnpm install --frozen-lockfile --ignore-scripts; pnpm build:vercel</automated>
</verify>

**Done:** The runbook describes the same working-directory and output assumptions as `vercel.json`, and the exact root install plus filtered Next.js build completes when initiated from the app-root context Vercel uses.
