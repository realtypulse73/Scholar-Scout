# Quick Task 260726-0qr: Project Document Index and Codex Guidance Reference

### 2. Wire the index into project guidance

**Files:**

**Action:** Add a concise durable instruction requiring the index to be read at the start of every project task and requiring it to be updated when an important document changes.

**Verify:** `AGENTS.md` contains a direct relative link to `PROJECT-INDEX.md` and an explicit read/update rule.

**Done:** The index is reachable from the instruction payload that Codex receives for this repository.
