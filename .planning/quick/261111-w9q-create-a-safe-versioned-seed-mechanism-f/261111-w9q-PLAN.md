# Quick Task 261111-w9q: Version the official Greater Houston catalogue seed

## Scope

Replace reliance on the ignored local runtime document with a version-controlled, public catalogue seed. The seed must contain only the five verified official-source records, the existing Phase 11 community-pathway fixture, public snapshot metadata, and the already committed project-owned image paths. It must not copy accounts, audit state, secrets, or other persisted runtime data.

## Tasks

1. Create a typed, versioned seed factory that builds the isolated Phase 11 fixture history and the active official-source snapshot with canonical digests and manifests.
2. Use the seed only when a data store is newly initialized; preserve the existing persisted-document read path without automatic rewrites or merges.
3. Add clean-store and seed-integrity tests for the five exact URLs, image mappings, fixture isolation, snapshot validity, and no-write read behavior. Run focused tests, typecheck, lint, JSON/format checks, then commit locally only.
