# GSD Effective-Use Training

## Goal

Create a standalone, interactive HTML lesson that teaches a Codex user how to choose and use GSD Core workflows effectively.

## Scope

- Explain the GSD Core phase loop and why its artifacts matter.
- Teach practical command selection, including quick, fast, debugging, and phase work.
- Include interactive command practice, scenario decisions, a compact cheat sheet, and a final readiness check.
- Cite the original archived repository and the active GSD Core repository.

## Implementation

1. Build one dependency-free, accessible HTML file under `output/` with embedded CSS and JavaScript.
2. Verify that the file opens as valid HTML and that its interactive buttons and quiz logic are present.
3. Record the output and verification in the quick-task summary without touching unrelated in-progress product files.

## Must Haves

- A learner can identify the standard discuss → plan → execute → verify → ship loop.
- A learner can select an appropriate GSD command for common work situations.
- A learner can complete a practical mini-simulation and receive useful feedback.
- The training clearly notes that `gsd-build/get-shit-done` is archived and points to GSD Core for current documentation.
