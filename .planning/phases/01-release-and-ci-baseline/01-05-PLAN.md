| Failure alert to incident response | A GitHub incident issue guides operational decisions while production data may be evolving. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-13 | Tampering / Availability | rollback procedure | high | mitigate | Require an incident assessment, fresh snapshot/export safeguards, and deliberate human rollback; do not automate a deployment reversal. |
| T-01-14 | Repudiation | release evidence | medium | mitigate | Require the named CI check results, deployment smoke report, and incident/runbook links as verifiable release evidence. |
| T-01-SC | Tampering | operational installation instructions | high | mitigate | Normalize all active operator commands to the pinned Corepack pnpm and frozen lockfile contract. |
</threat_model>
