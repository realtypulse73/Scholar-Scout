## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pull request source to GitHub Actions | Contributor-controlled code and manifests enter hosted build and test jobs. |
| CI check runs to main protection | GitHub rules use displayed status names as the merge authorization signal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Tampering | GitHub Actions dependency install | high | mitigate | Every job enables the pinned Corepack pnpm, uses the committed lockfile, and runs an explicit frozen install with lifecycle scripts disabled. |
| T-01-04 | Repudiation | ci.yml quality checks | medium | mitigate | Give each required behavior one stable displayed check name and run all six for every PR/main event without path filters. |
| T-01-05 | Denial of service | pnpm cache | low | accept | Caching only the pnpm store is optional performance optimization; jobs remain correct on cache miss and never cache node_modules or secrets. |
| T-01-SC | Tampering | package-manager bootstrap in CI | high | mitigate | Corepack consumes the reviewed packageManager pin rather than downloading an ad-hoc workflow package. |
</threat_model>
