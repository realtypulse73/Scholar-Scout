# Phase 07.1: Futuristic Student Journey Visual System - Context

**Gathered:** 2026-09-21
**Status:** Ready for planning

<domain>
## Phase Boundary

Create a cohesive visual system for the existing Scholar Scout experience: an app-wide futuristic typeface, a bright red/white/silver palette, and calm student-side motion on illustrated lifestyle scenes. This phase redesigns presentation and motion without adding new student-product capabilities or changing live data behavior.

</domain>

<decisions>
## Implementation Decisions

### App-wide typeface
- **D-01:** Use Space Grotesk as the app-wide typeface direction. Apply it consistently to headings, body copy, navigation, controls, and the existing pages rather than limiting it to a new landing screen. The founder selected it after reviewing Space Grotesk, Sora, and an Orbitron/Sora combination.

### Red, white, and silver visual balance
- **D-02:** Use a light, hopeful white-and-silver foundation across pages and cards. Do not introduce black or charcoal page backgrounds.
- **D-03:** Use bright red for primary actions and selected states, with soft blush-red highlights for warmth. Red is an accent rather than a dominant reading background, so the student-oriented experience remains optimistic rather than warning-like.
- **D-04:** Use a deep blue-gray only where necessary for readable text, borders, and accessible contrast; it must not read as a dark theme.

### Student-side scene motion
- **D-05:** On lifestyle scenes that depict people, keep the civilian half visually still and give the student half subtle, slow, looping movement.
- **D-06:** Motion may combine walking students with contextual journey details such as a passing train/bus or a soft moving light trail. It should enrich the scene without distracting from copy, controls, or accessibility.
- **D-07:** Start scene motion automatically, but honor `prefers-reduced-motion` by rendering a still version for visitors who request less motion.

### the agent's Discretion
- Define exact token values, animation durations, easing, responsive behavior, and which existing people-based scenes receive which approved motion motif.
- Preserve readable contrast for all text and interactive controls; use existing app content and routes rather than inventing new marketing claims.

</decisions>

<specifics>
## Specific Ideas

- The intended emotional tone is bright, hopeful, and aspirational—not serious, heavy, or dark.
- The student side usually carries the movement because it represents forward progress from civilian life to student life.
- Motion should feel fluid but not busy: it is a background enhancement, never an attention competitor.
- The palette recommendation is informed by context-sensitive color research: red should be reserved for energy and action rather than used as an achievement-screen background.

</specifics>
