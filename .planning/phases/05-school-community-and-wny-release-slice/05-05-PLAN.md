## Security posture

OWASP ASVS Level 1 applies. Every high-severity threat is a release blocker until its named mitigation and automated check pass.

## Trust Boundaries

| Boundary | Description |
|---|---|
| browser → inbox API | Untrusted message and attempted sender identity cross into an authenticated submission handler. |
| inbox API → community quota provider | The same reservation controls inbox and public-note writes and can be unavailable. |
| stored inbox request → public response | Private sender/contact fields must not cross the API boundary. |
