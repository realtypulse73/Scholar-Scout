## Security posture

OWASP ASVS Level 1 applies. Every high-severity threat is a release blocker until its named mitigation and automated check pass.

## Trust Boundaries

| Boundary | Description |
|---|---|
| browser → community APIs | Untrusted message, route ID, and attempted identity cross into authenticated write/report handlers. |
| community API → quota provider | A quota reservation controls an abuse-prone write and may be unavailable. |
| store → public DTO | Private stored identity and moderation state are transformed for unauthenticated public reads. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | S/E | submission/report routes | high | mitigate | Derive actor only from NextAuth session; reject unauthenticated requests and ignore browser identity fields. |
| T-05-02 | D | shared quota | high | mitigate | Confirm installed sliding limiter API, reserve account-scoped capacity before write, and fail closed when unavailable. |
| T-05-03 | I | public community response | high | mitigate | Use named DTO mappers with exact-shape route tests. |
| T-05-04 | T/R | report transition | high | mitigate | Stable-ID idempotent review creation with bounded CAS retry and race fixture. |
| T-05-SC | Tampering | npm installs | high | mitigate | No package install is authorized; inspect the already installed Upstash package/API only. |
</threat_model>
