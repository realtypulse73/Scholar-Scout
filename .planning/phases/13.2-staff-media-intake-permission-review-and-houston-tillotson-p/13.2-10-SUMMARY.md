# Phase 13.2 Plan 10: Direct Upload Authorization Gap Closure Summary

**Private Vercel Blob PUT capabilities now require the current invited Draft owner and exact server revision at both signing and callback boundaries.**

## Performance

- **Duration:** 48 min
- **Started:** 2026-10-02T09:33:00-04:00
- **Completed:** 2026-10-02T10:21:35-04:00
- **Tasks:** 2/2
- **Files modified:** 6

## Accomplishments

- Added a server-only authorizer that checks the trusted account actor, active invitation, Draft lifecycle, opaque package ID, and exact revision immediately before `issueSignedToken`.
- Bound the signed callback and completion mutation to the approved revision, so stale or removed packages cannot update private submission state.
- Updated client video/poster uploads to replay the original server-issued revision and added lifecycle, route, and component regression coverage.

## Task Commits

1. **Task 1: Re-authorize one current Draft owner before a private Blob PUT token is signed** — `a37ae6b` (test), `5dfeb7a` (feat)
2. **Task 2: Send the issued revision through the private client upload contract and prove the repaired boundary builds** — `9c9e7b3` (test), `566ae38` (feat)

## Files Created/Modified

- `apps/web/lib/server/contributor-media.ts` — validates current private ownership and revision before signing and completion mutation.
- `apps/web/app/api/contributor-media/upload/route.ts` — passes the trusted actor through the direct-upload path and signs only server-derived paths.
- `apps/web/components/contributor-media/ContributorMediaIntake.tsx` — carries only the opaque package ID and server-issued revision.
- `apps/web/__tests__/lib/server/contributor-media.test.ts` — verifies lifecycle ownership and denial states.
- `apps/web/__tests__/api/contributor-media.test.ts` — verifies signer invocation is denied for uninvited, foreign, stale, and unknown-package payloads.
- `apps/web/__tests__/components/ContributorMediaIntake.test.tsx` — verifies the client uses one revision across both uploads and completion.

## Decisions Made

- Keep server-owned object paths out of browser and callback response shapes; only opaque ID, kind, and revision cross the boundary.
- Make completion reject obsolete package revisions before marking an object received, extending the token authorization boundary through the callback mutation.
