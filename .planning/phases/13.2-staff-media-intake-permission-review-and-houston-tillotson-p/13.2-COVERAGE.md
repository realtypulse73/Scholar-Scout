# API Coverage — Vercel Blob contributor-media pilot

> Full coverage by default. Opt-outs are explicit, reasoned decisions.

| capability | decision | reason |
|---|---|---|
| Vercel Blob private object storage | INTEGRATE | Holds the video and poster outside learner access while the pilot is in draft or review. |
| Vercel Blob server-authorized client upload | INTEGRATE | Avoids a Function body upload path and lets the server issue a capability only after invitation and revision checks. |
| Vercel Blob private server read and application proxy | INTEGRATE | A released opaque public identifier is authorized by the application before bytes stream; private Blob names never cross the public boundary. |
| Vercel Blob private object deletion or quarantine | INTEGRATE | Contributor removal must invalidate public delivery and apply the approved retention action without altering provider facts. |
| Uploaded MP4 metadata inspection | INTEGRATE | A server-owned inspection result, approved at the provenance checkpoint, decides the inclusive 30,000 ms readiness limit. |
| Direct public Blob URL delivery | OPT-OUT | A public URL could expose an unreviewed asset or bypass withdrawal authorization. |
| Function multipart video upload | OPT-OUT | The bounded pilot uses authorized direct-to-private storage rather than placing video bytes in a route body. |
| Google Maps, Street View, scraped or provider visual ingestion | OPT-OUT | The locked pilot permits neither third-party asset collection nor a named-campus representation. |
| Vercel Blob replacement of the catalogue document adapter | OPT-OUT | This phase adds a separate bounded binary store and retains the existing incrementally written catalogue document. |
