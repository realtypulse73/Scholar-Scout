<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Student request to account onboarding API | Untrusted support values could enter the durable profile. |
| Legacy persisted profile to consumer | Prior mixed taxonomy values could reappear in matching. |
| Student browser to local referral interaction | Sensitive selection may reveal fixture information but cannot cross to persistence, matching, analytics, URL, or provider boundaries. |
| Pre-launch fixture to public release | Test-only destination metadata must not be represented as an available real service. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-02 | Information disclosure | onboarding API, persisted profile, and referral panel | high | mitigate | Focused Jest rejects referral-only request values, normalizes legacy profiles, and proves no local referral side effect crosses a data boundary. |
| T-07-06 | Tampering | referral fixture directory | high | mitigate | Directory contains only conspicuously non-live fixture URLs; the committed release gate requires reviewed real metadata before public release. |
| T-07-09 | Spoofing | fixture referral presentation | high | mitigate | Consent UI marks fixtures as test-only and makes no availability claim; public release remains blocked on owner-reviewed sources. |
</threat_model>
