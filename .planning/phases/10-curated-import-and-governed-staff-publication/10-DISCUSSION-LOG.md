## Staff review

| Option | Description | Selected |
|---|---|---|
| Creator self-approves | The person who creates a record may approve it. | |
| Different active reviewer | A different active staff member approves regular staff records. | ✓ |
| Two reviewers | Two active staff members approve. | |

**User's choice:** A different active reviewer approves regular-staff records. The user clarified that an administrator may publish without separate review only after the automated checklist passes.

**Notes:** The automated checklist covers source, facts, freshness, claim wording, regional boundary, and media-rights status. Failed candidates stay private with correction instructions; post-approval edits require review again.

## Publication recovery

| Option | Description | Selected |
|---|---|---|
| Side-by-side resolution | Compare attempted and current versions, then choose values. | ✓ |
| Reload current version | Discard the attempted edit and start again. | |
| Newest save wins | Overwrite other staff changes. | |

**User's choice:** Side-by-side resolution. Choosing an older value requires a written reason.

**Notes:** An authorized reviewer can create a checked emergency version for serious errors. Final-check failures quarantine only the failed record and do not block passing records.

## Media-rights review

| Option | Description | Selected |
|---|---|---|
| Documented permission | Ownership, licence, provider approval, or approved embed with source/expiry. | ✓ |
| Public link | A provider website link is enough. | |

**User's choice:** Use both rights-documented media and factual text/source fallback when proof is unavailable.

**Notes:** Check rights before scheduled and emergency releases; remove expired/revoked/uncertain media immediately. Missing rights block media, not a valid factual record.
