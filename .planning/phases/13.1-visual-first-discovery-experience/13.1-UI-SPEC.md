# Phase 13.1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | Existing custom Tailwind design system; no new component-system initialization |
| Preset | Not applicable — `components.json` is absent; the project already has governed manual primitives and tokens |
| Component library | Existing native React/Tailwind controls and `components/ui` primitives |
| Icon library | None; use visible text controls rather than icon-only controls in this phase |
| Font | Space Grotesk (`--font-space-grotesk`), with Arial/Helvetica/sans-serif fallback |

**Existing-token contract:** Extend `background`, `silver`, `blush`, `ink`, `brand`, `focus`, `warning`, and `danger` from `apps/web/tailwind.config.ts`; do not add a parallel token set. Retain the existing 8px `rounded-card`, `min-h-touch` (44px), `shadow-panel`, `focus:ring-focus`, and `min-w-0`/responsive reflow patterns.

## Phase Boundary and Non-Negotiables

- The visual layer is part of every catalogue-discovery arrival, not an optional visual-explorer destination, sign-in step, story prerequisite, or ranking signal.
- Render learner visuals only from the reviewed public snapshot's existing `renderableMedia` projection or a local Scholar Scout-owned illustration. Never fetch, scrape, embed, upload, proxy, or infer a visual at learner request time.
- A visual may introduce a possible learning environment. It must never contain a factual opportunity card, factual status, source state, comparison control, provider official action, or a claim of attendance, affiliation, placement, endorsement, eligibility, or outcome over the imagery.
- Facts, uncertainty, sources, verification actions, saving, comparison, filters, and official next actions remain in their existing source-first cards/sections immediately after the visual introduction. A visual never changes the review snapshot, filtering, sort order, qualification ordering, or visibility of any pathway class.
- Do not add a third-party map/Street View renderer, iframe, remote image/video URL, copied Street View screenshot, user content, analytics field, persistence field, or query parameter. An approved embed remains non-renderable until separately authorized for terms, privacy, attribution, accessibility, and source-rights review.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|

| Body / controls | 16px | 400 | 1.5 |

## Visual Composition and Interaction Contract

### Automatic arrival

1. On every `/programmes` discovery render with the reviewed snapshot available, place an **Arrival panel** directly after the catalogue title/intro and before filters, results count, and factual cards. It is in normal document flow, never a modal, overlay, carousel, timer, or route redirect.
2. The panel is a two-column layout at `md` and above (copy first, visual second) and one stacked column below `md` (copy first, visual second). It has 24px padding, a 16px gap on phone / 32px on desktop, white content surface, silver field, and a restrained CSS-only red/silver radial depth layer behind—not over—legible content.
3. Render the fixed semantic structure: `section` with `aria-labelledby`; a 14px eyebrow **A first look at possibility**; 32px heading **Explore what learning could look like**; body **Start with a calm visual introduction, then compare reviewed facts, sources, and next steps.**; a primary **Browse reviewed opportunities** button/link that moves to `#catalogue-results-heading`; and a text **Skip visual welcome** link with the same destination. Neither action changes a filter, order, profile, sign-in state, or URL.
4. The visual side has a plain visible media label and, where media exists, the existing **About this media** disclosure. It has no overlaid provider name, facts, CTA, source state, card, or action. Factual provider information begins only in the following source-first results region.
5. `/stories` may remain a clearly secondary companion link, but it cannot be the only visual entry, replace the arrival panel, gate discovery, or carry visitor/profile state. Remove the condition that hides the visual introduction merely because `visualItems.length === 0`.

### Arrival visual selection and truthful fallback

Use this deterministic hierarchy; execute it from the existing reviewed resolver/projection boundary, never from browser discovery:

| Priority | Rendered state | Required label / behavior |
|----------|----------------|---------------------------|
| 1 | Approved local provider or Scholar Scout media projection | Preserve its reviewed label, local alt/caption, `About this media` provenance, and non-affiliation language. A local preview may be shown but does not autoplay in the arrival panel. |
| 2 | Separately authorized Maps/Street View | **Not implemented in this phase.** No iframe, screenshot, remote URL, or placeholder that implies authorization may render. |
| 3 | Local Scholar Scout-owned illustration | Label exactly **Scholar Scout illustration — not an official photograph of this provider campus.** Provide descriptive alt text that calls it an illustration, not a verified campus image. Preserve the existing provenance disclosure. |
| 4 | No renderable approved asset | Render the complete factual fallback: no image-shaped empty frame, no simulated campus photography, and no unverified provider title. Show the existing source-first fallback heading **Visual media needs rights review**, its explanatory copy, and continue directly to filters/results/facts. |

For normal local UAT, provide or retain deterministic safe fixtures for: one reviewed local preview, one Scholar Scout illustration, and one no-media factual fallback. A missing approved provider visual must still demonstrate the labelled illustration or truthful factual state; no network dependency is allowed.

### Catalogue-wide atmosphere

- Add one scoped catalogue-atmosphere class to the discovery overview and focus/detail shells. It uses only CSS gradients, existing red/white/silver tokens, and `aria-hidden` decorative nodes behind the content plane. It never uses background images, background video, canvas, a media feed, or autoplay.
- Depth is static at all breakpoints: one low-opacity red radial shape no larger than 18rem and one silver linear/radial wash. Maintain a white or silver solid surface behind all text, controls, and source evidence. Decorations have `pointer-events: none` and never create a scroll width.
- Extend the existing focus decoration so it is static rather than animated. Under `prefers-reduced-motion: reduce`, retain the same static, lower-contrast depth (or an equivalent solid silver surface); do not leave a blank/unstyled shell.
- Do not change the existing narrow center-card exception: only one eligible local-preview card nearest the viewport center may loop muted video, it must be scroll/center bounded and user-pauseable, and it is always paused under reduced motion. The arrival panel itself never receives this autoplay exception.

## Responsive, Accessibility, and Source Contracts

| Area | Buildable contract |
|------|--------------------|
| Keyboard and focus | Arrival links/buttons are native focusable controls with a 2px visible `focus` ring. Arrival is not auto-focused. `Browse reviewed opportunities` and `Skip visual welcome` move focus to the results heading after navigation/scroll. The media disclosure opens with focus in the dialog, closes on Escape/Close, and returns focus to **About this media**. |
| Screen reader | Use a concise section name **Visual welcome**; decorative atmosphere is `aria-hidden`; approved media keeps its reviewed alt/accessible name. Read the Scholar Scout illustration disclaimer as normal visible text. Announce no autoplay as a behavior, not as a hidden instruction. |
| Motion | All ambient decoration is static. `prefers-reduced-motion` disables the center-card loop and leaves the visible control/status as **Motion is paused because your device prefers reduced motion.** Do not substitute flashing or a continuously changing gradient. |
| Controls | All controls meet 44px target height, retain text labels, and have no hover-only essential information. The primary CTA and skip link work with mouse, keyboard, touch, and screen-reader virtual cursor. |
| Reflow | At 320px through supported phone/tablet widths, stack the arrival content, wrap long provider/source labels, use `min-w-0`, and keep page-level horizontal overflow absent. The filter/results layout remains one column until the existing large-screen rail breakpoint. |
| Transparency | The media label, non-affiliation statement, and provenance disclosure stay adjacent to a rendered visual. Facts, source date/state, verification links, comparison, save, and official action remain outside media and remain available even if media fails. |
| Safety and agency | No required account, story, personal input, referral selection, behavioural measurement, location inference, ranking change, or pathway suppression is introduced. Opening a detail from a visual always reaches Scholar Scout's factual detail route first. |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Browse reviewed opportunities |
| Secondary skip action | Skip visual welcome |
| Arrival eyebrow | A first look at possibility |
| Arrival heading | Explore what learning could look like |
| Arrival body | Start with a calm visual introduction, then compare reviewed facts, sources, and next steps. |
| Illustration label | Scholar Scout illustration — not an official photograph of this provider campus. |
| Empty state heading | No reviewed cards to show |
| Empty state body | Your active filters removed all reviewed cards. Reset or widen the filters to return to this metro’s reviewed snapshot. For snapshot/coverage absence: This does not mean no opportunities exist. |
| No-media fallback | Visual media needs rights review. This factual opportunity page does not display provider or learner media yet. Facts and source actions remain available below. |
| Error state | We couldn’t load the reviewed opportunities. Refresh to try again. We will not show unreviewed or stale client-side results. |
| Playback-rejection state | Preview could not start automatically. Facts and source actions remain available. |
| Destructive confirmation | None — this phase adds no destructive action. |

Prohibited copy: “official campus photo” for an illustration; “best,” “eligible,” “safe match,” “you will,” “guaranteed,” recruitment pressure, attendee/student testimony, provider endorsement, or outcome claim.

## UI Considerations

The post-verification UI-consideration probe resolved **35 applicable states: 14 explicit and 21 backstop; 0 unresolved.** Backstop rows must become held-out automated or visual-regression evidence during planning; they are not assumed complete merely because the contract exists.

### Arrival panel

- `empty` — **explicit:** No approved asset renders the factual no-media fallback, with no image-shaped frame or provider claim.
- `loading` — **backstop:** A non-media structural placeholder appears until the reviewed snapshot exists; no fact is presented as loaded.
- `error` — **backstop:** Failure shows the documented Refresh error and never substitutes stale or unreviewed media.
- `populated` — **explicit:** One normal-flow Visual welcome presents concise copy, reviewed local media or a labelled illustration, and text navigation before factual results.
- `overflow` — **backstop:** At 320px, content stacks and wraps without horizontal page overflow.
- `long-text` — **backstop:** Labels, captions, and disclaimers wrap in their content column and remain fully visible.

### Catalogue results

- `empty` — **explicit:** Zero cards show the honest reviewed-catalogue empty copy and reset/widening action; coverage absence never claims that opportunities do not exist.
- `loading` — **backstop:** A structural non-media loading state persists until the reviewed catalogue is ready.
- `error` — **backstop:** Load failure uses the documented refreshable error and never renders unreviewed client-side results.
- `populated` — **explicit:** Source-first factual cards follow the welcome, retaining facts, sources, comparison, save, and official action outside imagery.
- `partial` — **explicit:** Each record independently resolves to approved local media, labelled illustration, or factual fallback while factual actions remain present.
- `overflow` — **backstop:** Card, source, and action content wraps or reflows at 320px with no horizontal overflow.
- `zero-one-many` — **backstop:** Zero uses the honest empty state; one retains source-first order; many retain all visible cards with existing bounded playback arbitration.
- `long-text` — **backstop:** Provider, source, and action text wraps without hiding a disclaimer, status, or source.

### Media provenance disclosure

- `empty` — **explicit:** Absent required provenance makes media non-renderable, routing to the factual no-media fallback instead of an empty disclosure.
- `loading` — **backstop:** The disclosure opens only from reviewed local data; tests confirm it never exposes incomplete loading content.
- `error` — **backstop:** If provenance cannot be presented, the dialog closes or says so truthfully while factual actions stay usable.
- `populated` — **explicit:** The dialog provides reviewed source, permission basis, month/year, supplied attribution, and non-affiliation language.
- `overflow` — **backstop:** Long content wraps in a scrollable dialog without clipping essential provenance.
- `long-text` — **backstop:** Long attribution, source, and permission strings wrap rather than truncate.

### Reviewed snapshot states

- `empty` — **explicit:** Missing approved media routes to a labelled illustration where available or factual fallback; zero results retain honest empty copy.
- `loading` — **backstop:** Loading uses the structural placeholder and does not start media or show inferred content.
- `error` — **backstop:** Refreshable error copy appears without legacy client data or remote-media retry loops.
- `populated` — **explicit:** The deterministic local fixture renders a reviewed local preview, labelled illustration, or factual fallback without network dependency.
- `partial` — **explicit:** Mixed media availability resolves per record without hiding source-first factual content.
- `overflow` — **backstop:** Snapshot-derived text and cards pass the 320px wrapping/no-overflow regression.
- `zero-one-many` — **backstop:** Fixtures cover one preview, one labelled illustration, and one no-media fallback; list counts remain truthful across zero, one, and many.
- `long-text` — **backstop:** Source metadata and fallback text wrap and stay visible at supported widths.

### Catalogue atmosphere and playback control

- `catalogue-atmosphere.overflow` — **backstop:** Decorative nodes stay behind content, pointer-inert, and cannot create horizontal scroll width.
- `catalogue-atmosphere.long-text` — **explicit:** Atmosphere carries no text; all titles and source labels retain solid readable surfaces and normal wrapping.
- `preview-playback-control.empty` — **explicit:** Without approved local preview media, no playback control renders; labelled illustration or factual fallback applies.
- `preview-playback-control.loading` — **backstop:** Playback is not attempted until an eligible reviewed local preview is ready.
- `preview-playback-control.error` — **explicit:** Rejected preview start shows the documented visible status and preserves facts/source actions without retry looping.
- `preview-playback-control.populated` — **explicit:** Only the nearest visible eligible card may loop muted local media; its text-labelled pause control reports playing or paused state.
- `preview-playback-control.long-text` — **backstop:** Text playback controls wrap or grow while keeping a 44px target and never become icon-only.

## Operational Safeguards and Acceptance Behavior

### Required seams

| Seam | Contract |
|------|----------|
| `CatalogueDiscoveryOverview` | Replace the conditional optional-explorer first impression with the always-rendered arrival panel; retain filters, all-visible result cards, qualification behavior, and existing one-center-card playback arbitration. |
| `DiscoveryPreviewSlot` | Reuse only its reviewed local renderer, factual fallback, provenance disclosure, pause control, and reduced-motion behavior. Add the explicit illustration disclaimer at the composition layer without a remote-media branch. |
| `CatalogueFocusView` | Apply the same static catalogue atmosphere and preserve visual-then-facts order, factual sources, equal compare/official actions, and no horizontal overflow. |
| `catalogue-publication` / `catalogue-discovery` | Preserve `resolveRenderableMedia` and the snapshot-only `renderableMedia` DTO boundary. Do not expose raw candidates, embed URLs, rights decisions, or remote sources to learner components. |
| `globals.css` / `StudentJourneyScene` | Reuse the existing bright red/white/silver CSS-only motif; scope static catalogue classes and reduce motion without adding global unrelated animation. |

### Automated acceptance matrix

| Scenario | Required assertion |
|----------|--------------------|
| Automatic arrival | `/programmes` renders one **Visual welcome** before filters/results for a reviewed snapshot with a local preview, illustration, or no media; it does not depend on sign-in, `/stories`, or `visualItems.length`. |
| Source-first separation | Arrival DOM contains no provider factual card, fact status, source-state, compare, save, or official-provider action over/in the media region; the following factual cards retain all of them. |
| Fallback truthfulness | Valid local preview renders local media/provenance; illustration renders the exact disclaimer; absent/invalid/expired/revoked/remote-only media renders factual fallback with no `img`, `video`, `iframe`, remote URL, or copied-Street-View branch. |
| UAT fixtures | Test fixtures exercise a reviewed local preview, Scholar Scout illustration, and no-media fallback without network mocks. |
| Agency | Normal/qualification ordering, metro/pathway filters, card count, comparison/save actions, and official links are unchanged by visual state; every pathway remains browseable. |
| Motion | Arrival media never calls `play`; only one nearest visible eligible catalogue card may receive `shouldPlay`; manual pause, viewport loss, and `prefers-reduced-motion` all pause it. |
| Atmosphere | Catalogue decorative nodes are `aria-hidden`, pointer-inert, static, and do not use `video`, `iframe`, remote asset URLs, timers, or animation under reduced motion. |
| Keyboard/dialog | Tab order reaches arrival actions, filters, factual actions, and **About this media**; dialog focus/close/Escape/return behavior is verified. |
| Responsive | At 320px, 768px, and desktop, no horizontal page overflow; the arrival stacks correctly at phone size; content/source/disclaimer text remains visible and readable. |
| Regression | Existing source state/date, verification links, all-visible empty state, comparison/official-action parity, and test suites for `CatalogueDiscoveryOverview`, `DiscoveryPreviewSlot`, `CatalogueFocusView`, `catalogue-publication`, and `catalogue-discovery` remain green. |

### Human UAT release checks

1. In a local fixture, open discovery as a signed-out visitor. Confirm the arrival is visible without visiting Stories, no personal data prompt appears, skip/CTA lead to factual results, and normal filters/order are unchanged.
2. Review local preview, labelled illustration, and factual-fallback states. Confirm that no illustration could be mistaken for an official campus photograph; provenance and non-affiliation language are understandable; facts/sources/actions remain more actionable than the visual.
3. At phone width and with keyboard/screen reader, tab through the arrival, filter controls, media disclosure, factual source links, comparison, and official action. Confirm no clipped content or horizontal overflow.
4. Enable reduced motion, scroll cards through center, and manually pause a preview. Confirm ambience remains calmly static; arrival does not play; no loop runs under reduced motion; a video never continues after it loses center/visibility or is paused.
