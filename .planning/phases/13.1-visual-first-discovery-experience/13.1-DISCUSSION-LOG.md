## Discovery arrival composition

| Option | Description | Selected |
|--------|-------------|----------|
| Immersive backdrop | The first factual opportunity floats over a campus visual. | |
| Visual strip | A campus visual leads a conventional list. | |
| Arrival panel | A visual welcome hands off to clear factual cards. | ✓ |

**User's choice:** Arrival panel.
**Notes:** The user wants the strongest possible initial pull while keeping factual information readable and action-oriented.
