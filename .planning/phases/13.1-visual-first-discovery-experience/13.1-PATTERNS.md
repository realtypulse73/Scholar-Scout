## Shared Patterns

### Reviewed snapshot and media-rights boundary

**Sources:** `apps/web/lib/catalogue-publication.ts` lines 754-792; `apps/web/lib/catalogue-discovery.ts` lines 162-198.  
**Apply to:** every new visual composition and test fixture.

```ts
const local = reviewed.find((candidate) =>
  candidate.kind === 'local-preview' && isEligibleCandidate(candidate, now),
);
if (local) return { renderableMedia: toRenderableMedia(local), mediaFallback: false };

const illustration = reviewed.find((candidate) =>
  candidate.kind === 'illustration' && isEligibleCandidate(candidate, now),
);
if (illustration) return { renderableMedia: toRenderableMedia(illustration), mediaFallback: false };
return { mediaFallback: true };
```

`CatalogueRenderableMedia` is deliberately only `local-preview | illustration` with a local `assetPath` (publication lines 73-84); `isLocalMediaPath` accepts `/media` or `/images` and rejects traversal (lines 844-846). `buildCatalogueDiscoveryModel` forwards only `record.renderableMedia` (discovery lines 193-198). Browser code must select from `item.renderableMedia` or render the slot’s factual fallback—never re-evaluate candidates or use `embedUrl`.

### Source-first action separation

**Sources:** `CatalogueFocusView.tsx` lines 68-83 and 106-117; `CatalogueDiscoveryOverview.tsx` lines 160-217.  
**Apply to:** visual welcome and static atmosphere additions.

Visual regions may contain reviewed alt/caption/label/provenance/non-affiliation wording only. Facts, status, evidence, verification links, comparison, save, filter controls, and official actions remain in following existing source-first regions. Styling cannot change normal ordering, visibility, metro/pathway filters, or action parity.

### Motion and accessibility

**Sources:** `DiscoveryPreviewSlot.tsx` lines 26-56 and 84-101; `CatalogueDiscoveryOverview.tsx` lines 62-114.  
**Apply to:** arrival and existing factual card loop.

The welcome is static because it never supplies `playback`. Existing factual-card loop stays the sole exception: one intersecting nearest local preview, muted/inline, user-pauseable, and disabled under `prefers-reduced-motion`. Decorations are `aria-hidden`, pointer-inert, clipped inside their shell; native text-labelled controls retain `min-h-touch` and `focus-visible:ring-2 focus-visible:ring-focus`.

### Static CSS-only atmosphere

**Sources:** `CatalogueFocusView.tsx` lines 47-64; `globals.css` lines 48-57; `tailwind.config.ts` lines 14-43.  
**Apply to:** overview title/welcome shell and detail/focus shell only.

Use a positioned content plane over a white/silver surface and static, low-opacity brand/silver gradient decoration. Do not reuse `StudentJourneyScene`: it depends on `/images/scholar-scout-transition-v1.png` and animated `.student-motion-layer`/`.student-light-trail` rules (its component lines 10-35; CSS lines 31-46), which violate this phase’s static, catalogue-scoped constraint.
