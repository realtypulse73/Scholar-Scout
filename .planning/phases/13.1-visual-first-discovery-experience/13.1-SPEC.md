# Phase 13.1: Visual-First Discovery Experience — Specification

**Created:** 2026-09-28
**Ambiguity score:** 0.12 (gate: ≤ 0.20)
**Requirements:** 7 locked

## Goal

The reviewed `/programmes` catalogue changes from an optional visual explorer into an automatic, rights-safe visual welcome that leads every visitor to source-first factual discovery without changing student choice or media safety.

## Background

Phase 13 already projects only reviewed, local `renderableMedia` through the catalogue DTO and provides `DiscoveryPreviewSlot`, factual fallback, provenance disclosure, and one centred-card playback controller. `CatalogueDiscoveryOverview` still hides its visual entry when `visualItems.length` is zero; its local test paths are not checked-in public assets. Phase 13 browser UAT remains outstanding, so Wave 0 must establish truthful local fixtures and complete that gate before this phase can be released.

## Requirements

1. **VIS-01 Automatic source-first welcome**: Every reviewed `/programmes` render has one normal-flow Visual welcome before filters/results.
   - Current: The visual explorer is conditional on media-bearing result cards.
   - Target: Welcome is independent of identity, Stories, personal input, ordering, and `visualItems.length`; facts/actions remain below it.
   - Acceptance: DOM tests prove welcome precedes filters/results and contains no provider facts, source state, save/compare, or official action.

2. **VIS-02 Truthful media hierarchy**: Arrival consumes only the reviewed DTO and resolves local preview, labelled Scholar Scout illustration, or factual no-media fallback.
   - Current: The resolver and preview component exist but composition lacks the required disclaimer and automatic fallback entry.
   - Target: No browser-side rights selection, remote URL, iframe, embed, or copied Street View branch exists.
   - Acceptance: Tests cover local, illustration, invalid/remote/expired/revoked, and absent states; illustration visibly says it is not an official provider photograph.

3. **VIS-03 Safe local fixture foundation**: Wave 0 supplies rights-evidenced local fixture records for preview, illustration, and factual fallback and closes Phase 13 browser UAT.
   - Current: Tests reference paths not present in public assets and Phase 13 UAT is outstanding.
   - Target: A neutral Scholar Scout-owned illustration and neutral local UAT preview are checked in with reviewed provenance; no-media remains asset-free.
   - Acceptance: Local UAT runs all three states without network access and Phase 13’s required browser UAT is recorded before release work proceeds.

4. **VIS-04 Static catalogue atmosphere**: Overview and focus shells gain scoped CSS-only, static red/white/silver depth.
   - Current: Focus decoration animates and vanishes under reduced motion.
   - Target: Decoration is `aria-hidden`, pointer-inert, behind a solid readable plane, remains lower-contrast under reduced motion, and creates no horizontal overflow.
   - Acceptance: Component/CSS contract tests and phone/tablet/desktop UAT prove static, visible, no-overflow behavior.

5. **VIS-05 Motion boundary**: Arrival never starts media playback; only the existing centred eligible local card can loop muted playback.
   - Current: Card playback arbitration already exists.
   - Target: Manual pause, centre/visibility loss, and reduced-motion preference all stop card playback; no wider autoplay exception is added.
   - Acceptance: Media-mock tests prove arrival never calls `play` and card controls preserve the bounded behavior.

6. **VIS-06 Accessible responsive evidence**: Welcome, source actions, provenance dialog, and catalogue states remain usable at 320px, 768px, and desktop.
   - Current: Jest covers DOM behavior but not live layout widths.
   - Target: Labels/disclaimers wrap, native 44px controls and dialog focus/Escape return work, and zero/one/many states remain truthful.
   - Acceptance: Held-out component tests cover loading/error/long-text/overflow branches; browser UAT covers widths, keyboard, and screen reader review.

7. **VIS-07 Dependency gate**: Phase 13.1 implementation cannot release until its Wave 0 fixture work has completed the outstanding Phase 13 browser verification.
   - Current: Roadmap names Phase 13 as a dependency but its verified media baseline lacks the required browser evidence.
   - Target: The safe fixture foundation is the explicit preflight bridge, then remaining 13.1 work may release.
   - Acceptance: Plan and release evidence show completed Phase 13 UAT before final Phase 13.1 verification.

## Boundaries

**In scope:** automatic welcome; reviewed local preview/illustration/factual fallback; neutral local UAT assets and provenance; static scoped atmosphere; motion/accessibility tests and browser evidence; Phase 13 UAT bridge.

**Out of scope:** Maps/Street View or third-party renderers; provider-site scraping or remote media; provider-specific claims in generated art; ranking, profiling, sign-in gating, referrals, or persistence changes; whole-app visual redesign; expanded autoplay.

## Constraints

Retain Next.js/React/TypeScript/Jest and the governed server resolver → DTO boundary. Add no packages, API routes, database fields, embeds, or browser-side candidate data. The neutral fixture assets are Scholar Scout-owned and may not imply provider affiliation.

## Acceptance Criteria

- [ ] One normal-flow Visual welcome precedes factual catalogue controls for every reviewed snapshot.
- [ ] Media branches render only local reviewed preview, exact labelled illustration, or factual fallback.
- [ ] Wave 0 local fixtures/provenance exist and close Phase 13 browser UAT before release.
- [ ] Arrival never autoplays; the existing single-card pause/reduced-motion contract remains intact.
- [ ] Atmosphere is static, CSS-only, `aria-hidden`, pointer-inert, and width-safe.
- [ ] Source actions and provenance dialog retain keyboard/focus behavior and 320px–desktop readability.
