## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Source assertion → factual evidence | Source data can be stale, incomplete, conflicting, or misrepresented as current. |
| Employer / wage source → catalogue contract | Pay and training statements can be misread as employment, salary, or placement commitments. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-07 | Tampering | `FactEvidence` and freshness classifier | high | mitigate | Required field-level provenance, injected-clock thresholds, and non-current handling for incomplete/stale/future evidence. |
| T-09-08 | Spoofing | employer training disclosure | high | mitigate | Controlled payer/commitment unions and separate validated pay/commitment evidence; no prose inference. |
| T-09-09 | Information disclosure | evidence / wage contract | medium | mitigate | Public catalogue record types omit re-entry, personal qualification, identity, and ranking fields. |
| T-09-10 | Repudiation | wage context | medium | mitigate | Require independent dated authority/source/verification action and an informational-context label. |
| T-09-SC | Tampering | package installation | high | mitigate | No packages are installed in Phase 9; existing TypeScript/Jest tooling only. |
</threat_model>
