<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| launcher environment -> child Next process | Only launcher-selected non-production settings and an opaque fixture identifier enter the adapter-owning process. |
| supervisor -> fixture lifecycle route | A unique opaque per-run capability permits only fixed no-body lifecycle operations inside the adapter-owning Next runtime. |
| fixture lifecycle -> governed catalogue | Only server-side governed create/read/delete operations may create the programme records seen by browser pages. |
| launcher cleanup -> filesystem | Cleanup may remove only the directory created for this run. |
## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-02 | Tampering | fixture adapter | high | mitigate | Reject production/external settings and force child JSON storage. |
| T-06-03 | Elevation of Privilege | fixture access | high | mitigate | No fixture route, client identity, credential, or external target. |
| T-06-04 | Tampering | cleanup | high | mitigate | Test exact `mkdtemp` ownership and child exit before removal. |
| T-06-15 | Information Disclosure | launcher output | medium | mitigate | Redact fixture paths, cookies, credentials, and environment values. |
| T-06-17 | Tampering | programme fixture | high | mitigate | Create/read/delete deterministic fixture records only through the governed catalogue boundary; fixture mode rejects ordinary seed fallback and browser-selected sources. |
| T-06-18 | Spoofing | lifecycle transport | high | mitigate | The internal route is production-denied, rejects browser-shaped/body/query requests, and requires a generated per-run capability that is held by the Node supervisor only. |
