## Trust Boundaries

| Boundary | Description |
|---|---|
| Public discovery item → visual card/detail | Evidence must remain intact and no presentation layer may turn it into a personal decision. |
| Stored media metadata → preview space | Media presence cannot bypass rights, consent, attribution, caption/transcript, expiry, or fallback requirements. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-11-04 | Tampering | detailed opportunity route | medium | mitigate | Rebuild item/navigation only from the allowlisted discovery model and stored snapshot; unknown IDs fail through the route's existing not-found response. |
| T-11-05 | Information disclosure | preview boundary | high | mitigate | The slot accepts no media URL and renders no provider/learner media; Phase 13 owns evidence-backed rendering. |
| T-11-06 | Spoofing | official next action | medium | mitigate | Render the validated stored HTTP(S) source URL with its source label, date/status, and `rel="noreferrer"`; never build destinations from query input. |
| T-11-SC | Tampering | package installation | high | mitigate | No packages are installed. |
</threat_model>
