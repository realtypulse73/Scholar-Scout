<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff-reviewed candidate → immutable public snapshot | Untrusted media metadata must become a narrow validated public projection. |
| public snapshot → browser detail UI | Learner rendering must not infer rights or make a provider/media request. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Tampering | publication media resolver | high | mitigate | Validate each bounded candidate, resolve it in D-03 order, persist only the selected safe projection, and test every precedence branch. |
| T-13-02 | Information Disclosure | detail preview | high | mitigate | Consume only the snapshot projection, expose no embed payload or third-party renderer, continue valid-but-unrenderable embeds to an eligible labelled illustration, and avoid remote provider loading. |
| T-13-03 | Spoofing | media disclosure | medium | mitigate | Present rights label, attribution, and nearby non-affiliation text with an accessible dialog. |
</threat_model>
