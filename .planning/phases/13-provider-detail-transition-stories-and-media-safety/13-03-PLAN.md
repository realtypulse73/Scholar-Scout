| Boundary | Description |
|----------|-------------|
| local editorial story records → public route | General transition copy can otherwise be mistaken for provider testimony or outcome evidence. |
| story destination → catalogue browse route | Navigation must retain explicit allowed filters and never select a learner’s location/profile. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-07 | Spoofing | story copy and visual proximity | high | mitigate | Keep copy general, carry visible non-affiliation disclosure, and use only factual Scholar Scout destinations. |
| T-13-08 | Information Disclosure | story route | low | accept | The route is public and contains fixed local records; it reads no account, profile, or user submission state. |
| T-13-09 | Denial of Service | motion/interaction | medium | mitigate | Use fixed native markup, no timed advancement, and reduced-motion-safe decoration. |
