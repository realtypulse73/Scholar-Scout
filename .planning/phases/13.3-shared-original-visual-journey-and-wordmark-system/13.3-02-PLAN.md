## Objective

Apply the shared visual system and original wordmark across learner-facing routes without changing operational or governed-media surfaces.

## Tasks

1. Add a route-aware learner visual shell with deterministic theme groups. Use it for learner pages only; exclude `/admin`, `/contribute/media`, and the accessibility UAT route.
2. Preserve each route's existing components, data reads, actions, and cards. The shell may supply page-level reading-panel transparency but must not alter source/verification, account, auth, or media-workflow content.
3. Replace the brand text treatment with an original broad wordmark built from the existing local typographic system and icon. Retain an accessible Scholar Scout label and visible focus behavior.
4. Add focused tests for theme routing, excluded operational paths, and brand semantic structure.
