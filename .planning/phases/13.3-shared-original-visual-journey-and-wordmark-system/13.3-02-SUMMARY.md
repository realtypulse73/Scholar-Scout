# Learner route integration

The app root now wraps learner routes in the shared visual shell. Admin, contributor-media, and accessibility-UAT routes remain free of the decorative layer. Route selection is based only on pathname; it does not consume learner data or infer personal history.

The dignity-first re-entry scene is scoped to generic stories context, never the sign-in flow or personalized routes. Verification is recorded with the phase-wide validation pass.
