# Phase 13.3: Shared Original Visual Journey and Wordmark System - Specification

## Requirements

1. **VIS-08:** Five original, repository-owned, generic Scholar Scout transition-scene assets exist with a recorded manifest and no third-party school/provider imagery or text.
2. **VIS-09:** Learner-facing route groups use a shared scene shell with deterministic themes, readable content panels, and no changes to catalogue facts, rank, account data, or authorization.
3. **VIS-10:** Decorative scene motion is CSS-only, non-interactive, and fully disabled by reduced-motion; narrow layouts remain readable without horizontal overflow.
4. **VIS-11:** The shared Scholar Scout wordmark is original, broad, modern-futuristic, accessible, and not a reproduction or close imitation of third-party branding.
5. **VIS-12:** Admin, contributor-upload, and accessibility-test routes stay quiet/static, and existing contributor-media review/release controls retain their current behavior.

## Boundaries

### In scope

- Original editorial scene assets and a local asset manifest.
- A reusable learner-route visual shell, route-theme mapping, reading-panel treatment, and CSS-only decoration.
- Shared wordmark implementation and focused automated/manual accessibility checks.

### Out of scope

- Provider/school-specific visual claims or individual-school art.
- Student-contributed media workflow changes, contributor rights/review/release changes, or Vercel Blob changes.
- User personalization, data collection, analytics, auth, catalogue ranking, release scheduling, or Production deployment changes.
- Video, autoplay, remote embeds, third-party image services, and simulated human movement.

## Acceptance criteria

- Five scene themes are visible only as generic Scholar Scout editorial context and each asset is recorded as original app-owned art.
- Learner routes show a consistent visual language; the visual layer never blocks reading, focus, controls, evidence, or facts.
- Reduced motion has no active decorative animations or transforms; mobile still exposes readable controls and no horizontal page overflow.
- Admin/contributor routes do not receive animated imagery, and existing media governance tests remain green.
- The wordmark is distinctive and original, with its accessible link label continuing to identify Scholar Scout.
