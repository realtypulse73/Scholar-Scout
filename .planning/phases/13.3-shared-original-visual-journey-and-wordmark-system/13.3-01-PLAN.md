## Objective

Create and record the five original generic scene assets, then introduce a reusable non-interactive scene backdrop with a complete reduced-motion fallback.

## Tasks

1. Generate and visually inspect five text-free original editorial backdrops; save selected assets under `apps/web/public/images/journeys/` with stable theme names. Add the ownership/use manifest. The re-entry scene must meet the dignity constraints in `13.3-CONTEXT.md`.
2. Implement the decorative backdrop inside the route-aware `LearnerVisualShell`. Keep art out of the accessibility tree, keep decorations pointer-inert, and layer content above an opaque/translucent reading surface.
3. Extend CSS with one bounded motion treatment that affects only decorative overlay layers and has an explicit reduced-motion no-animation/no-transform state.
4. Add focused tests for theme validation, decorative isolation, and a source-level reduced-motion contract.

- Manual browser check confirms a themed scene, readable panel, keyboard focus, and a fully still reduced-motion rendering.
