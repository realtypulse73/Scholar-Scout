# Phase 13.3: Shared Original Visual Journey and Wordmark System - Context

**Gathered:** 2026-10-26
**Status:** Ready for planning

<domain>
## Phase Boundary

Create a reusable, original Scholar Scout visual scene system and an original wide wordmark for learner-facing pages. The system uses five generic, editorial transition scenes with a readable content layer and CSS-only decorative motion. It changes presentation only: no catalogue, account, authentication, contributor-media, release, or Production behavior changes.

</domain>

<decisions>
## Implementation Decisions

### Original scene set
- **D-01:** Create five text-free, lifelike, Scholar Scout-owned editorial raster scenes: rural-to-college, city-to-college, workplace-to-training, broad next-step learning transition, and dignified adult re-entry-to-opportunity.
- **D-02:** Each scene is a paired/split composition: a familiar starting setting and a destination-learning setting. They are generic Scholar Scout context, never evidence about a learner, named school, programme, provider, admission, employment, or outcome.
- **D-03:** The re-entry scene shows an adult walking away from a fence with a small personal box toward an open opportunity. It must convey agency and hope; exclude uniforms, police, mugshots, threat, fear, or criminalizing cues.
- **D-04:** Use original app-owned scenes across learner-facing routes. Do not block this foundation on unique art for every school; school-specific original art is a future scalable workstream.

### Presentation and motion
- **D-05:** Scene imagery sits behind translucent but high-contrast reading panels. One scene half receives restrained CSS-only decorative motion; the photographed people remain still rather than simulating a person moving.
- **D-06:** Motion is non-essential, `aria-hidden`, pointer-inert, never timer-driven, and fully still under `prefers-reduced-motion: reduce`.
- **D-07:** Assign scenes deterministically by route group, not by timed rotation, randomization, learner data, location, profile, or passive behavior. Mobile collapses to a short static visual band plus readable content.
- **D-08:** Admin and contributor-upload routes remain operationally quiet and static. The accessibility UAT fixture remains neutral.

### Brand identity
- **D-09:** Replace the current simple text treatment with an original, wider, fuller, modern-futuristic Scholar Scout wordmark. It may take high-level character inspiration from vintage wide retail typography, but must not reproduce Sears, Sears Roebuck, or any third-party lettering, logo, wording, or trade dress.

### Governance and scope fences
- **D-10:** Record every generated app scene in a repository asset manifest with ownership, generic use, non-provider status, alt/presentation treatment, and revision metadata. Student-contributed uploads remain the only media class using invitation, attestation, independent review, release, revocation, and private delivery workflows.
- **D-11:** Preserve all existing factual catalogue controls, source/verification hierarchy, private media gates, user data, authentication, weekly release behavior, and Production configuration.

### the agent's Discretion
- Choose exact route-to-scene assignments, responsive image formats, CSS animation durations, and visual token values while meeting readability, performance, and reduced-motion requirements.

</decisions>

## Existing Code Insights

### Reusable Assets
- `StudentJourneyScene`: already separates `aria-hidden`, pointer-inert decorations from content, and has a reduced-motion rule.
- `ScholarScoutBrandMark`: centralizes the current icon and word treatment.

### Established Patterns
- App Router pages use route-owned `<main>` shells, so the shared visual layer must not override cards, form controls, factual evidence, or keyboard focus.
- `globals.css` owns animation keyframes and its existing reduced-motion reset is the safe extension seam.

### Integration Points
- A route-aware visual wrapper can provide a fixed decorative backdrop only for learner routes.
- A manifest under `apps/web/public/images/journeys/` can document the five app-owned assets without involving governed provider media.

<specifics>
## Specific Ideas

- Bright, hopeful, text-free editorial images with usable quiet areas for reading panels.
- No logos, school names, recognisable provider branding, or textual claims inside art.
- Keep the student-facing experience coherent without making every school page appear endorsed by a background image.

</specifics>

<deferred>
## Deferred Ideas

- A scalable batch of school-specific original artwork, only after the shared five-scene foundation is verified.
- Any student/profile-selected scene or personalized imagery; it would create a data-governance decision outside this presentation phase.

</deferred>
